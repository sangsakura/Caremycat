Caremycat 咕噜罐头管家

GitHub Pages部署：
1. 解压ZIP。
2. 将 index.html、README.txt 和 images 文件夹上传到 Caremycat 仓库根目录。
3. GitHub Settings > Pages > Deploy from a branch > main > /(root)。
4. 打开 https://sangsakura.github.io/Caremycat/

功能：
- iPhone Safari兼容的单文件应用
- 已开罐优先、最多2罐、14天期限、新罐间隔2天
- 每日约80g、30天动态计划
- 实际摄入与计划预测分开
- 钙、磷、镁和数据覆盖率
- 搜索库存、记录开罐、实际摄入、体重、导入导出
- 图片路径支持 images/ 目录；未提供图片时显示罐头占位图

注意：内置的是示例库存。原始 index.txt 不是HTML源码；如要恢复完整库存，请使用网页内导入备份功能导入本工具导出的JSON。
